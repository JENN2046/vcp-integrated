| 切片 | 隔离实测 | Core 单聊退出的旧职责 |
| --- | --- | --- |
| Canvas、Workspace、Live Reference | ToolBox 的实际 WebSocket 完成节点绑定和返回，运行桌面读取适配器。验证 Canvas 话题匹配、登记工作区文件更新、移动会话无法冒充节点和断开后零上游请求。Canvas 正文由测试表面注入。 | 桌面聊天生成本轮上下文及接管执行。节点继续持有资源的读取和归属。 |
| AgentAssistant | 实际 AA 插件执行子轮和归档，Core 按父 Work、调用和子任务身份读回报告。后续上下文读取同一已核对报告。 | 旧移动 Work 子任务账本、AA 子轮的 HTTP 环回及通用回调发布。AA 原生循环、取消和归档继续生效。 |
| TopicSponsor | 已授权桌面提交后退出，Core 直接接纳同空间目标单聊并完成目标回复。旧授权票据、旧 Journal 和旧 HTTP 执行计数为零。 | 桌面节点转交既有话题的留言及旧共享执行接纳。 |
| Flowlock | 桌面退出后，Core 依据正式回复的原生控制标记执行一次续写。跨主体停止被拒绝，模型发出 Stop 后停止。 | Core 话题的桌面计时器和本地续写入口。输入框仍由桌面表面处理。 |
| 上下文压缩 | 手动和自动均运行 Core 共用的原生摘要路径。覆盖历史变更拒绝、丢回执后读回一次生成的检查点、按预算自动执行及检查点后的上下文。 | Core 话题的桌面摘要请求、检查点生成及提交协调。旧准备和提交入口返回明确迁移状态。 |

## 运行与限制

- 原生套件 345 通过、6 跳过。协作套件 61 通过。PWA 和桌面 preload 构建通过。
- 真模型烟测使用本机 SmolVLM 与 llama.cpp。三次模型请求均完成。Core 提交摘要，后续请求实际读取该摘要并裁剪旧正文。此小模型未保留测试代号，烟测只证明执行与读回链路。 [真实模型回执](real-compaction.json)
- Live Reference 限于节点已登记的工作区。未绑定的绝对路径不会转发。Canvas 需要节点仍可观察相应话题。
- 仍有动态引用或 AA 任务未结算的历史会阻止手动压缩，自动压缩会保留该轮上下文。TopicSponsor 沿用已授权桌面发起及既有目标单聊的范围。收到留言的 Work 不自动再向其他话题转发。
- 扩展桌面检查有一项 ProjectForge Windows 包装断言受缺少 projectforge_indexer.exe 影响。R2 未构建 Windows 包。
- Resident 签封、生产可信客户端和 WebTransport 延续独立工作项。
