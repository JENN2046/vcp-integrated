## 原生入口与切片

| 切片 | 复用入口与正式写入边界 |
| --- | --- |
| 统一上下文和附件 | 沿用原生历史窗口、Tavern 和请求封装。附件复用既有解析、哈希存储与鉴权，正式绑定随 Core 消息提交。 |
| 实时资源 | 按资源所属宿主查询和授权。核对桌面引用与后端可达资源的边界后接入已验证的资源类型。 |
| AgentAssistant | 子任务状态、结果与控制继续由原生 AA 持有。Core 需要保留父 Work 与原生任务身份、结算状态及断线读回。 |
| Flowlock | 复用原生输入框及续写控制。桌面 DOM 操作沿用桌面可用性边界。 |
| 上下文压缩 | 复用 VCPChat 摘要生成与原生检查点语义，由 Core 核对输入版本和持久提交。 |
| TopicSponsor | 复用原生留言目标与投递授权。Core 单聊的接纳及正式写入走同一 Work 和消息入口。 |

每个切片验证真实入口、执行和读回后，撤掉该切片在 Core 单聊中的旧职责。旧路径继续承载尚未迁移的调用者。

### 已完成：可携带附件

Core 单聊支持现有原生格式校验器识别的 UTF-8 文档和有文本层的 PDF。发送和追问复用同一原生上下文组装入口，文件原件由已授权的会话按哈希读取。历史投影传输文件元数据，已提取的正文用于服务端上下文。没有可读文本的附件在接纳前返回明确错误。实时桌面引用与扫描 PDF 另行迁移。

隔离测试使用真实 PDF 解析、桌面运行时和两个独立配对会话。上传记录过期后，原件和上下文仍可读取。Scope 越权和空附件发送被拒绝。原生定点 37 项通过，协作套件 61 项通过。

### 已完成：空闲单聊的手动压缩

桌面沿用原生压缩模型请求、取消流程和检查点格式。Core 按主体、话题、历史变更序号和配置版本核对来源。来源变化或 Work 处于需要结算的状态时拒绝提交。正式检查点写入 Core 一次，桌面持久化原提交意图以处理丢回执。下一条 Work 使用原生历史窗口选取检查点之后的上下文，整份可见历史继续提供查询。

隔离测试通过真实桌面运行时、原生压缩服务与回环模型夹具。覆盖编辑后的旧来源拒绝、提交回执丢失时重开、只生成一次摘要、手机会话追问使用检查点，以及旧附件和压缩入口对 Core 单聊的拒绝。自动压缩、运行中的原生工具与 AA 续接继续按各自切片迁移。

本批回归使用 Node 24。原生套件 340 项通过、6 项跳过，协作套件 61 项通过，PWA 构建通过。未重新使用实体手机。

### M2-R2 实时资源

Core 通过 VCPDistributedServer 原生 WebSocket 按桌面 Source 绑定读取实时信息。Canvas 需要节点显示相应话题，Workspace 由原生索引展开。已附加的登记工作区 Live Reference 在每轮重新读取，正式消息保留引用元数据。原始绝对路径引用仍由其桌面入口处理。节点断开时 Work 返回明确的不可用状态，模型调用数保持原值。

隔离用例使用实际 ToolBox WebSocket、桌面资源读取适配器及临时工作区。覆盖节点别名歧义、实时文件更新、Canvas 话题绑定、移动端无法冒充节点以及断线拒绝。

### M2-R2 AgentAssistant 与 TopicSponsor

Core 记录 AgentAssistant 的父 Work、调用、原生子任务和模型轮次。原生 AgentAssistant 继续负责循环、取消和归档，内层模型轮次走进程内 ToolBox。桌面与 PWA 查询原生报告时按会话作用域复核。隔离用例使用真实 AgentAssistant 和回环模型，验证正式归档、按原身份读回及后续上下文。Core 子任务退出旧共享执行账本和通用回调发布。

TopicSponsor 在已授权桌面发起的 Core Work 上复用发送方、目标及话题绑定校验。向既有 Core 单聊留言时直接接纳目标 Work，正式写入由 Core 裁决。隔离用例覆盖桌面不再参与执行、目标话题生成回应及旧授权票据和 Journal 无写入。

### M2-R2 Flowlock 与摘要执行

Core 为主聊天解析原生 Flowlock 控制标记，以现有 Work 队列接续。续写提示标明 Flowlock 来源。桌面只投影 Core 会话状态并转交控制命令，输入框仍归桌面表面。Core 手动与自动压缩复用同一原生提示、摘要请求和检查点生成，正式提交与命令回执由 Core 持有。
