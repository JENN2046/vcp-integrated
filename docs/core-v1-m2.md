## 原生入口与切片

| 切片 | 复用入口与正式写入边界 |
| --- | --- |
| 统一上下文和附件 | 沿用原生历史窗口、Tavern 和请求封装。附件复用既有解析、哈希存储与鉴权，正式绑定随 Core 消息提交。 |
| 实时资源 | 按资源所属宿主查询和授权。核对桌面引用与后端可达资源的边界后接入已验证的资源类型。 |
| AgentAssistant | 子任务状态、结果与控制继续由原生 AA 持有。Core 需要保留父 Work 与原生任务身份、结算状态及断线读回。 |
| Flowlock | 复用原生输入框及续写控制。桌面 DOM 操作沿用桌面可用性边界。 |
| 上下文压缩 | 复用 VCPChat 摘要生成与原生检查点语义，由 Core 核对输入版本和持久提交。 |
| TopicSponsor | 复用原生留言目标与投递授权。Core 单聊的接纳及正式写入走同一 Work 和消息入口。 |

每个切片验证真实入口、执行和读回后，撤掉该切片在 Core 单聊中的旧职责。旧路径继续承载尚未迁移的调用者。

### 已完成：可携带附件

Core 单聊支持现有原生格式校验器识别的 UTF-8 文档和有文本层的 PDF。发送和追问复用同一原生上下文组装入口，文件原件由已授权的会话按哈希读取。历史投影传输文件元数据，已提取的正文用于服务端上下文。没有可读文本的附件在接纳前返回明确错误。实时桌面引用与扫描 PDF 另行迁移。

隔离测试使用真实 PDF 解析、桌面运行时和两个独立配对会话。上传记录过期后，原件和上下文仍可读取。Scope 越权和空附件发送被拒绝。原生定点 37 项通过，协作套件 61 项通过。
